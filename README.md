# Tutorial 8 - Java Swing Applications

This repository contains Problems 3, 4, 5, and 6 from Tutorial 8, implemented using Java Swing.

## Problem 3: Student Registration System
Uses JFrame, JTextField, JRadioButton, JComboBox, JButton, and JOptionPane for student registration.

## Problem 4: User Login and Preferences
Uses JTextField, JPasswordField, JCheckBox, and JOptionPane for login and preference selection.

## Problem 5: Student Course Management System
Uses JList, JTable, JButton, and JScrollPane to manage student course registrations.

## Problem 6: Text Editor Application
Uses JTextArea, JMenuBar, JMenu, JMenuItem, and JScrollPane to provide text editing features.

## Technologies
- Java
- Java Swing
- JDK

## How to Run
Open Terminal in this folder.

Compile a program:
javac StudentRegistration.java

Run it:
java StudentRegistration

Replace the filename and class name with those of the program you want to execute.
